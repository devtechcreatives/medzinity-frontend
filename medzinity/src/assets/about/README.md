Images for the About Us page.

Files are matched **by filename prefix**, so the extension and any suffix after
the slot name are free (`about-hero.webp`, `about-hero@2x.avif`, both work).
Supported: `.webp`, `.avif`, `.jpg`, `.jpeg`, `.png`.

| Slot            | Where it appears                          | Suggested crop      |
| --------------- | ----------------------------------------- | ------------------- |
| `about-hero`    | Full-bleed page header behind the title   | ~2400×1200, wide    |
| `about-purpose` | "Who We Are" — tall frame beside the copy | ~1000×1250, portrait|
| `about-story`   | "Our Story" — offset frame beside the copy| ~1000×1250, portrait|
| `about-join`    | "Join Us" band at the foot of the page    | ~2000×900, wide     |

Every slot is optional. A missing image falls back to the navy/blue gradient
panel, so the page stays finished-looking while this folder is empty.

The hero and join images sit under a navy scrim with white text over the left
side — keep the busy detail on the right half.
